02 · How it works

Guidelines and steps

Contribute original, useful material that another learner can open and study without extra context.

  1. 1
    Choose a source

    Use the guided LLM prompt or bring a pack you already built in Fydor.

  2. 2
    Check the content

    Validate the schema, then review translations, words, grammar, and chunks sentence by sentence.

  3. 3
    Submit for moderation

    Once every sentence is marked reviewed, the immutable version enters the moderation queue.

Before you startOnly submit content you have the right to share. Never include secrets, private data, or unlicensed source material.

Step 3

Import the generated pack

Paste one strict Fydor pack JSON object. Legacy single-lesson JSON is accepted and wrapped for you.

Model output is untrusted. The server checks size, nesting, duplicate keys, allowed fields, safe text, annotation surfaces, and schema compatibility before saving.
Step 3

Upload an existing pack

Choose a pack exported from Fydor. It will use the same validation, review, and moderation path as an LLM-generated pack.
